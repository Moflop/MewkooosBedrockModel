# 实验性静态网格使用入口

这些 API 面向需要优化较高精度静态模型的库使用者，仅供客户端使用。API 和实现仍可能变化，暂不推荐作为稳定的长期方案；普通模型渲染无需依赖它们。

调用方提供几何、不可变的几何 key 和实例状态，库负责缓存、上传、剔除与绘制。根据对象的使用方式选择入口：

- [即时与批量静态网格](static-mesh-api.md)：用于当前调用或渲染阶段的绘制，可复用缓存，并提供不支持时的原有绘制回退。
- [世界网格渲染组](world-mesh-rendering.md)：登记长期存在的世界对象，支持 INSTANCE 与 SECTION 策略、对象生命周期及普通 BER 回退。

## 使用边界

- 所有操作在客户端渲染线程执行，不要从公共初始化或专用服务器代码调用。
- INSTANCE 按对象应用实例矩阵；SECTION 按 `16×16×16` 区段组织几何。策略、资源或外观变化后需要重新准备，首次准备和策略切换存在预热窗口。
- 世界渲染组不处理透明排序和 shadow；SECTION 换版前可能保留旧成员快照。
- 资源重载后应通过资源 ID 重新取得模型，避免长期持有旧资源。几何 key、阶段边界和回退规则请按对应使用说明处理。
